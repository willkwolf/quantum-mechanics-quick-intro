# Quantum Origins

An interactive, premium scrollytelling web application exploring the birth of Quantum Mechanics from the Ultraviolet Catastrophe and the Blackbody radiation problem, featuring rigorous annotations from **Landau & Lifshitz** Course of Theoretical Physics.

---

## 🇪🇸 Español

### Características Clave
*   **Scrollytelling Interactivo**: Un viaje continuo de 13 secciones trazando el colapso de la física clásica.
*   **Simuladores Interactivos en SVG**: Simulador térmico de cuerpo negro, gráficos espectrales interactivos de Wien y Rayleigh-Jeans, rampa clásica vs. escalones de energía, y un simulador completo del efecto fotoeléctrico de Einstein.
*   **MathToggle**: Un control persistente en pantalla que permite alternar instantáneamente entre la notación escolar estándar ($E = h\nu$, $k_B$) y la notación teórica avanzada de **L. Landau** ($E = \hbar\omega$, $T$ en unidades de energía).
*   **Landau Companion**: Panel lateral dinámico con referencias de volumen (§63 de *Física Estadística* y §1 de *Mecánica Cuántica*), citas del libro y comparativas de formulación matemática.

### Comandos de Desarrollo
```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Generar compilación estática local
npm run build
```

## 🇺🇸 English

### Key Features
*   **Interactive Scrollytelling**: A seamless 13-section journey tracing the breakdown of classical physics.
*   **Interactive SVG Simulators**: Real-time blackbody cavity, Wien and Rayleigh-Jeans spectral charts, continuous vs. discrete energy ramps, and a fully functional Einstein's photoelectric circuit simulator.
*   **MathToggle**: A persistent UI element allowing students to dynamically toggle between standard school notation ($E = h\nu$, $k_B$) and **L. Landau** advanced theoretical notation ($E = \hbar\omega$, $T$ in energy units).
*   **Landau Companion**: A sliding sidebar with volume and section references (Vol. 5 §63, Vol. 3 §1), direct quotes, and rigorous mathematical comparisons.

### Development Commands
```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build and export static HTML locally
npm run build
```
